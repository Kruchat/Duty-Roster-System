# Duty-Roster-System

แอปตารางเวรครู AI (v21) — ไฟล์เดียว `index.html` เปิดในเบราว์เซอร์ได้เลย

## สิ่งที่แก้ใน v21

- วันที่ «วันนี้» ใช้วันจริง ไม่ล็อกที่ 15 พ.ย. 2025
- โมเดล Gemini อัปเดตเป็น `gemini-3.8-flash` (ค่าเริ่มต้น) พร้อม 3.6 / 3.5 / 2.5
- แชทไม่ผูก submit ซ้ำ และกด Enter ส่งได้ครั้งเดียว
- ลากย้ายเวรบนมือถือได้ และวางลงวันว่างได้ (ไม่ใช่แค่สลับชิป)
- ป้องกัน XSS ทั้งหน้าแรก รายการ โมดัล วันหยุด และ toast
- ตารางเวรว่างไม่ถูกบังคับกลับไปเป็นข้อมูลตัวอย่าง
- AI เขียนตารางทั้งก้อนได้ แต่ตรวจรูปแบบแถว และมีย้อนกลับ
- เพิ่ม/ลบเวรและวันหยุดเองจากหน้าจัดการและป๊อปอัปรายวัน
- API key ส่งผ่านหัว `x-goog-api-key` ไม่แปะใน URL
- นำเข้าไฟล์แบบ array เก่าจะไม่ล้างวันหยุด
- Google Sheet sync ส่งทั้งเวรและวันหยุด และมีปุ่มซิงค์ตอนนี้

ข้อมูลเดิมใน localStorage (`teacher_roster_data_v2` ฯลฯ) ยังใช้ได้

## วิธีใช้

1. เปิด [index.html](./index.html) ในเบราว์เซอร์ หรือเปิดจาก GitHub
2. ไปที่แท็บ **จัดการ** ใส่ [Gemini API Key](https://aistudio.google.com/apikey) ถ้าจะใช้แชท AI / ค้นหาวันหยุด
3. เพิ่มเวรเอง หรือให้ AI ช่วยจัดจากแท็บแชท
4. ในปฏิทิน ลากชื่อครูไปวันอื่นเพื่อย้าย หรือวางทับชิปอื่นเพื่อสลับ
5. สำรองข้อมูลด้วยปุ่มบันทึกลงเครื่อง

## Google Sheet (ไม่บังคับ)

วาง URL ของ Apps Script Web App ในหน้าจัดการ แล้ว Deploy ให้ Who has access = Anyone  
โค้ดตัวอย่างอยู่ในหน้าจัดการของแอป

## หมายเหตุ

- ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้น ไม่มีเซิร์ฟเวอร์ของแอปเอง
- อย่าแชร์ API key ในที่สาธารณะ
